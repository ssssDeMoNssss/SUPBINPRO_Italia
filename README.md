# SUPBINPRO ИТАЛИЯ

## Описание
Проект приложения для автоматизации создания торгового бота на платформе vk.com.

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ssssDeMoNssss/SUPBINPRO_Italia.git
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите скрипт `setup.bat` для настройки окружения.

## Использование
- Запустите бота:
  ```bash
  python bot.py
  ```
